# National examples

Model enrollment and achievement credentials for a fictional education system and anchor their digests locally. National recognition and interoperability are design goals, not validated results. Synthetic identities and data are used throughout. These source files compile as part of the `distribution:examples` module.

## runNationalEducation

Read [NationalEducationExample.kt](NationalEducationExample.kt) and run from the repository root:

```sh
./gradlew :distribution:examples:runNationalEducation
```

Use JDK 21 and the repository Gradle wrapper (`.\gradlew.bat` on Windows). Run `:distribution:examples:checkDocumentationExamples` for all runnable entry points and `:distribution:examples:test` for the module tests.

Read the source for the exact operations and assertions. In-memory anchor clients and registries do not validate hosted networks, institutional recognition or production custody. No real credentials should be used.
